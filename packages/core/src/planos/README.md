# Módulo: Planos

## Objetivo
Definir quais capacidades (módulos) um locatário pode usar conforme o plano.

## Responsabilidades
- Catálogo de módulos (ex.: LOCATARIOS, AUTENTICACAO, BACKUP, RELATORIOS_SIMPLES, etc.)
- Definição do Plano (básico, etc.)
- Regras: limites (ex.: número máximo de usuários) e habilitação por módulo

## Regras mínimas alinhadas ao produto
- Sempre habilitados: locatário, autenticação, backup
- Importação como migração: tratada como serviço/extra
- Exportação: relatórios simples sempre; relatórios complexos como extra
